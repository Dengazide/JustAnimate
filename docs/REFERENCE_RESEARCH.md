# Reference research and boundaries

The linked tutorial is “How to Make Viral Animated Shorts Using Claude (Full Workflow)” (https://youtu.be/OtbLL6OBNE4). Its public companion skill is https://github.com/mromidev/claude-animated-shorts.

The upstream repository publishes a skill, style bible, seven measured reports (motion, depth, textures, characters, lighting, outlines and grade), twenty contact sheets and selected reference frames. The public skill says its reference channel and full videos are private study material. The channel name is not identified in the public skill.

This project therefore does not claim to have downloaded ten videos from that channel or performed a new frame-by-frame analysis of those private uploads. It uses the published workflow and measurements as technical context only. It does not reproduce the upstream example short, the channel's scripts, characters, shots or distinctive artwork. The sample episode, voice, music, 3D world, props and characters are original.
