# Reusable asset library

Run the Blender asset generator or the trimesh fallback. It exports a named GLB library with:
- ASSET_Barrel, ASSET_Vat, ASSET_Crate, ASSET_Lantern
- ASSET_GeorgianTownhouse, ASSET_HandCart, ASSET_CobblestoneTile, ASSET_StreetTree
- ASSET_Character_Brewer_LightSkin, ASSET_Character_Woman_LightSkin, ASSET_Character_Watchman_LightSkin

Characters are original starter meshes with named parts, not finished facial rigs. Add armatures, skin weights, facial controls and animation actions for demanding close-ups. All assets are procedural originals; no third-party textures are bundled.
