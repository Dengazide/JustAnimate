# Reusable asset library

Run the Blender asset generator or the trimesh fallback. It exports a named GLB library with:
- ASSET_Barrel, ASSET_Vat, ASSET_Crate, ASSET_Lantern
- ASSET_GeorgianTownhouse, ASSET_HandCart, ASSET_CobblestoneTile, ASSET_StreetTree
- ASSET_Character_Brewer_LightSkin, ASSET_Character_Woman_LightSkin, ASSET_Character_Watchman_LightSkin

The episode's on-screen cast is drawn as high-resolution 2D canvas character cards in the skill's illustrated construction style: bean heads, ~3.5-head adult proportions, fine stick limbs, plum weighted outlines, lidded deadpan eyes, clean pale faces and shaded bean torsos. The GLB character meshes are optional 3D blockout assets, not the primary character design. All assets are procedural originals; no third-party textures are bundled.
